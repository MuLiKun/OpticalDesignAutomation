# Zemax 公差分析程序使用说明

> 面向使用者：如何运行、如何准备输入、输出结果怎么看。  
> 功能规格见 `公差分析程序_需求文档.md`；开发/测试记录见 `公差分析工具_开发进度与测试记录.md`；ZOS-API 实测坑见 skill `zemax-tolerance-analysis`。

---

## 1. 程序能做什么

给定一个 Zemax `zmx` 文件，程序可以自动完成：

1. 连接 OpticStudio，另存工作副本，不修改原始镜头；
2. 按标准模板、Zemax 当前设置或高级 Excel 配置生成/复用 TDE、MFE、TSC；
3. 运行脚本式 Monte Carlo 公差分析；
4. 保存 `.ZTD`、Worst/Best Case、日志和运行配置；
5. 读取 `.ZTD` 并导出统计 Excel。

---

## 2. 运行前准备

项目根目录：

```powershell
e:\zemax-skills-advance_TOL
```

Python 解释器：

```powershell
e:\zemax-skills-advance_TOL\.venv\Scripts\python.exe
```

运行前确认：

1. Zemax OpticStudio 可正常启动；
2. 待分析 `zmx` 文件可手动打开；
3. 输出目录有写权限；
4. 若使用 GUI 交互扩展连接，需在 OpticStudio 中点击 **编程 → 交互扩展**；
5. 推荐使用 `standalone` 连接模式，由程序后台启动 Zemax。

---

## 3. 推荐入口：GUI

从项目根目录运行：

```powershell
.\.venv\Scripts\python.exe -u tolerance_analysis\gui.py
```

GUI 支持：

- 普通标准模板模式；
- 使用 Zemax 当前设置模式；
- 高级 Excel 模式（含公差填写向导，见 §6.1）；
- 独立分析已有 `.ZTD`；
- 实时日志、运行计时、两段式取消（第一次温和取消，再点强制停止并关闭后台 Zemax）、打开结果目录；
- 自动导出统计 Excel。

连接模式：

| 模式 | 说明 |
|---|---|
| Standalone | 推荐。程序后台启动 Zemax，跑完释放 |
| GUI 模式 | 连接已打开并进入交互扩展等待状态的 OpticStudio |

## 4. 命令行入口

命令行入口：

```powershell
.\.venv\Scripts\python.exe -u tolerance_analysis\tol_run.py [参数]
```

常用命令：

```powershell
# 生成高级 Excel 配置模板
.\.venv\Scripts\python.exe -u tolerance_analysis\tol_run.py --init-template --config tolerance_analysis\tol_config_模板.xlsx

# 普通标准模板模式
.\.venv\Scripts\python.exe -u tolerance_analysis\tol_run.py --standard --zmx "镜头.zmx" --outdir "输出目录" --connect standalone --num-runs 20 --num-to-save 0

# 使用 Zemax 当前设置模式
.\.venv\Scripts\python.exe -u tolerance_analysis\tol_run.py --current-settings --zmx "镜头.zmx" --outdir "输出目录" --connect standalone --num-runs 20

# 高级 Excel 模式
.\.venv\Scripts\python.exe -u tolerance_analysis\tol_run.py --zmx "镜头.zmx" --config "配置.xlsx" --outdir "输出目录" --connect standalone

# 只校验配置，不连接 Zemax
.\.venv\Scripts\python.exe -u tolerance_analysis\tol_run.py --validate-only --zmx "镜头.zmx" --config "配置.xlsx"
```

常用参数：

| 参数 | 含义 |
|---|---|
| `--zmx` | 待分析镜头文件 |
| `--config` | 高级 Excel 配置文件 |
| `--standard` | 使用普通标准模板模式 |
| `--current-settings` | 使用 zmx 中已有 TDE/MFE |
| `--outdir` | 父输出目录 |
| `--connect` | `standalone` 或 `extension` |
| `--num-runs` | Monte Carlo 次数 |
| `--num-to-save` | 保存 worst/best case 数量 |
| `--comp-mode` | `无` / `全部优化DLS` / `全部优化OD` |
| `--no-read` | 跑完不读取 ZTD |
| `--validate-only` | 只校验输入 |
| `--read-only` | 只读取镜头信息 |
| `--init-template` | 生成配置模板 |

## 5. 三种分析模式怎么选

| 模式 | 适合场景 | 是否需要 Excel |
|---|---|---|
| 普通标准模板 | 日常快速分析，推荐普通使用者使用 | 不需要 |
| 使用 Zemax 当前设置 | zmx 中已经手工配置好 TDE/MFE | 不需要 |
| 高级 Excel | 需要自定义公差、评价函数、REPORT、补偿器 | 需要 |

普通标准模板模式当前支持：

- 产品类型：`RX` / `TX`；
- 模板：`标准分析` / `完整视场分析`；
- TX 不含 MTF，且固定不做后焦补偿 / TSC 优化；
- 标准模板会自动使用 Zemax 主波长；
- 公差结束面默认取像面前一面；
- `全部面=否` 时，标准分析会直接读取 zmx 文本识别 `AF32ECO` / `D263TECO` 滤光片：TX 只取最后一个滤光片之后的镜头面，RX 只取第一个滤光片之前的镜头面，并自动跳过 RX 物面后的双面平板玻璃；未识别到滤光片则退回全部面；
- 视场映射默认启用，并输出 `field_mapping.txt`。

## 6. 高级 Excel 配置

高级 Excel 模式读取 `输入_*` sheet，`示例_*` sheet 只作参考。

| Sheet | 用途 |
|---|---|
| `输入_公差向导` | 一类公差一行，批量生成 TDE |
| `输入_公差明细` | 逐行追加 TDE 操作数，可粘贴 Zemax TDE 数据行 |
| `输入_评价函数` | MFE 操作数 |
| `输入_REPORT` | TSC `REPORT` 分项与统计列名 |
| `输入_运行参数` | MC 次数、分布、补偿器、输出选项 |

常用运行参数：

| 参数键 | 说明 |
|---|---|
| 蒙特卡洛次数 | Monte Carlo 样本数 |
| 保存数量 | 保存 worst/best case 数量 |
| 统计分布 | 正态 / 均匀 / 抛物线 |
| 补偿器模式 | `无` / `全部优化DLS` / `全部优化OD` |
| TSC优化周期 | TSC 中 `OPTIMIZE n` 的周期 |
| 中心波长号 | 评价函数使用的波长号；标准模板自动取主波长 |
| 后焦补偿面 | 需要追加 TDE `COMP` 的面号；留空则不加 COMP |
| 补偿Min / 补偿Max | 补偿器允许行程（相对名义厚度 mm，如 -0.1/0.1）；写入 TDE COMP 硬限位，并在补偿 MF 中加 CTGT/CTLT 厚度软约束；留空=自由调整 |
| 保存WorstCase / 保存BestCase | 任一为 Y 即开启 Zemax worst/best 保存开关 |
| 输出统计Excel | 跑完后自动读取 ZTD 并导出统计 Excel |

补偿器规则：

- `无`：不写优化行、不生成补偿 MF、不加 TDE `COMP`；
- `全部优化DLS` / `全部优化OD`：生成补偿 MF，TSC 写 `OPTIMIZE`；
- 后焦补偿面大于 0 时，额外在 TDE 末尾追加 `COMP`；
- 脚本式蒙卡下 Zemax 工具栏的补偿器下拉可能显示“无”，实际以生成的 `.TSC` 为准。

### 6.1 公差填写向导（推荐给不想手写 Excel 的用户）

不熟悉 `输入_公差明细` 的用户可以用 GUI 内置向导自动生成高级 Excel 配置：

1. 主界面选择「高级 Excel」模式并选好 zmx 文件；
2. 点「配置检查…」→「公差填写向导…」；
3. **分组确认页**：程序扫描 zmx 文本自动列出镜片（带面号+材料），滤光片/平板玻璃
   默认不勾选；可拆分胶合组或合并相邻组；
4. **逐镜片填写页**：一次填一片，14 项中文公差（半径/厚度/面偏心/面倾斜/元件偏心/
   元件倾斜/面不规则/折射率/阿贝%/空气间隔等），留空=不做该项；支持按等级预填、
   「同上一片」「应用到剩余全部」；中断自动存草稿，下次打开可恢复；
5. **评价函数选择页**：选产品类型 RX/TX、视场序列 标准/完整，勾选 SPOT/GENC/MTF
   （频率可输入，TX 自动禁用 MTF）/指向类/焦距·FOV；
6. **汇总预览页**：只读确认全部公差行，并设置补偿器模式、后焦补偿面、补偿Min/Max
   （限制补偿器行程）、补偿线对（默认跟随 MTF 频率）、MC 次数、保存数量、
   是否保存 Worst/Best；
7. 点「确认生成」，生成 `公差填写_<镜头名>_YYYYMMDD_HHMMSS.xlsx`（写入主界面
   「输出目录」，未填则用 zmx 同目录；不覆盖任何已有文件），路径自动回填到
   主界面 Excel 框，直接点「开始分析」即可。

说明：指向/焦距/FOV/补偿器评价函数在运行期连接 Zemax 后自动生成，最终以结果目录
中的 `used_excel.xlsx` 为准。

非球面镜头说明：面偏心/面倾斜对应的 TSDX/TSDY/TSTX/TSTY 仅支持 Standard/
Irregular 面。程序会自动识别偶次非球面等非标准面，改用等价的单面元件操作数
TEDX/TEDY/TETX/TETY（面1=面2=该面，与 Zemax 官方向导写法一致），并在预览注释
中标记「非标准面单面元件组」，无需用户干预；面不规则（TIRR）不受影响。

## 7. 输出结果

用户选择的是父输出目录。每次运行会自动创建：

```text
公差分析_<镜头名>_YYYYMMDD_HHMMSS
```

结果目录常见文件：

| 文件 | 说明 |
|---|---|
| 工作副本 `.zmx` | 实际参与分析的镜头副本 |
| `used_excel.xlsx` | 本次实际使用配置快照 |
| `run_config.json` | 运行参数和元数据 |
| `run.log` | 日志 |
| `.ZTD` | Zemax 公差数据 |
| `_统计.xlsx` | ZTD 统计结果 |
| `field_mapping.txt` | 视场映射摘要，启用视场映射时生成 |
| `.TSC` | Zemax Tolerance 脚本，位于 Zemax DataDir 的 `Tolerance` 目录 |
| `.MF` | Merit Function，位于 Zemax DataDir 的 `MeritFunction` 目录 |

统计 Excel 包含：

- 名义值；
- Cpk1.33 下限 / 上限；
- 最大值、最小值、平均值、标准差、中位数；
- 每个 Monte Carlo 样本的原始值；
- TSC `REPORT` 分项；
- TDE 中的 `COMP` 项。

敏感度排序会写入统计 Excel 的 `敏感度Top20` / `敏感度诊断` sheet。

用途：识别每个 `REPORT` 指标下最敏感的公差项，辅助判断图纸严控项。

第一版规则：

- 优先复用 Monte Carlo 生成的同一份 `.ZTD`，不重复运行 Zemax；
- 每个 `REPORT` 指标单独排序；
- 每个指标只保留 Top 20；
- 不做 MTF、SPT、指向、焦距等跨类型综合总排名；
- 敏感度结果写入统计 Excel 的独立 sheet。

核心表 `敏感度Top20` 主要字段：

| 字段 | 说明 |
|---|---|
| REPORT指标 | 当前性能指标 |
| 排名 | 当前 REPORT 内排名 |
| 名义值 | 当前 REPORT 指标的标称值 |
| 公差项 | 对应 TDE 公差项 |
| 当前公差 | Min/Max 或等效公差幅值 |
| 值 | ZTD SensitivityData 给出的预计变化量，保留正负号 |
| 绝对值 | `值` 的绝对值，排序依据 |
| 风险方向 | 按指标方向标记不利/有利/需判断 |

## 8. 常见问题

| 问题 | 处理方式 |
|---|---|
| GUI 模式连不上 | 重新在 OpticStudio 点一次“交互扩展” |
| 写 TSC 报权限错误 | 用自己的前台终端启动程序，不要后台隐藏启动 |
| 运行期间没有逐次进度 | Zemax 脚本式蒙卡不暴露逐次进度，只显示总数和用时 |
| 补偿器下拉回读为“无” | 以 `.TSC` 中的 `OPTIMIZE` / `FASTFOCUS` 为准 |
| 统计列名是 `colN` | 未找到同名 `.TSC` 或无法反推 REPORT 表头，统计仍有效 |
| Excel 被占用 | 关闭已打开的统计 Excel 后重试，或使用自动备用文件 |
