# Zemax 公差分析自动化程序需求文档

> 面向维护者：记录当前功能规格、设计边界和后续规划。  
> 使用方法见 `公差分析程序_使用说明.md`；开发和测试记录见 `公差分析工具_开发进度与测试记录.md`。

---

## 1. 项目目标

将 Zemax 公差分析流程固化为配置驱动程序：

```text
选择 zmx → 生成/复用 TDE/MFE/TSC → 运行脚本式 Monte Carlo → 保存 ZTD → 导出统计 Excel
```

核心原则：

1. 不修改用户原始 zmx，只操作工作副本；
2. 普通用户可以不写 Excel；
3. 专家用户仍可用高级 Excel 完全控制；
4. 每次运行结果可追溯；
5. Zemax API 细节集中在代码和 skill 中维护，文档只保留规格。

## 3. 功能规格

### 3.1 普通标准模板模式

面向普通使用者，目标流程：

```text
选择镜头文件 → 选择产品/模板/次数 → 开始分析 → 获取统计 Excel
```

当前支持：

| 项 | 规格 |
|---|---|
| 产品类型 | `RX` / `TX` |
| 模板 | `标准分析` / `完整视场分析` |
| 公差等级 | 宽松 / 标准 / 严格 |
| 视场映射 | 默认开启，输出 `field_mapping.txt` |
| 主波长 | 运行期自动使用 Zemax 主波长 |
| 结束面 | 默认像面前一面 |
| 后焦补偿面 | RX 可按补偿模式自动/手动设置；TX 固定不补偿 |
| 临时配置 | 生成 UUID 文件名，避免覆盖用户文件 |

当前模板特性：

- RX：包含 Spot / GENC / MTF；
- TX：不含 MTF，固定 `补偿器模式=无`，不写 TSC 优化，不加 TDE `COMP`；
- 标准模板动态追加：
  - 中心指向偏移 `POINTING_DY_F0_mm` / `POINTING_DX_F0_mm`；
  - 焦距偏移百分比 `EFL_DELTA_PCT`；
  - 视场角 `FOV_Y_deg`；
  - 多视场指向角偏差 `POINTING_ANGLE_F*_deg`。

### 3.2 使用 Zemax 当前设置模式

面向已经在 zmx 中配置好 TDE/MFE 的用户。

当前策略：

1. 打开工作副本；
2. 不清空 TDE；
3. 不重建 MFE；
4. 读取当前 MFE 有效行；
5. 自动生成 REPORT/TSC；
6. 运行 Monte Carlo；
7. 导出统计 Excel。

补偿器规则：

- 若请求补偿，但当前 TDE 中没有 `COMP`，程序会关闭优化并记录日志；
- COMP 统计按 TDE 顺序定位，不靠表头模糊匹配。

### 3.3 高级 Excel 模式

面向项目专家，保留完整自定义能力。

Excel sheet：

| Sheet | 规格 |
|---|---|
| `输入_公差向导` | 向导式批量 TDE |
| `输入_公差明细` | 逐行追加 TDE，可粘贴 Zemax TDE 数据行 |
| `输入_评价函数` | MFE 操作数 |
| `输入_REPORT` | TSC `REPORT` 分项 |
| `输入_运行参数` | MC、补偿、分布、保存、统计输出 |

视场映射：

- 标准模板默认启用；
- 高级 Excel 可通过运行参数启用；
- 当前只支持 X/Y 主轴视场；
- 插入视场只作用于工作副本；
- 输出 `field_mapping.txt` 和 `run_config.json` 记录映射摘要。

### 3.4 ZTD 统计

统计 Excel 固定输出：

- 名义值；
- Cpk1.33 下限 / 上限；
- 最大值、最小值、平均值、标准差、中位数；
- MC 原始样本；
- TSC REPORT 分项；
- TDE COMP 项。

列名策略：

1. 优先从同名 `.TSC` 解析 `REPORT "标签" 行号`；
2. COMP 按 `run_config.json` 中的 TDE 元数据定位；
3. 无法识别时保留 `colN`，不中断导出。

## 4. 输出规格

每次运行生成独立结果目录：

```text
公差分析_<镜头名>_YYYYMMDD_HHMMSS
```

| 产物 | 规格 |
|---|---|
| 工作副本 `.zmx` | 始终生成，不改原文件 |
| `used_excel.xlsx` | 本次实际运行配置快照 |
| `run_config.json` | 运行参数、视场映射、REPORT/TDE 元数据 |
| `run.log` | 全流程日志 |
| `.ZTD` | Zemax 公差数据 |
| `_统计.xlsx` | 统计结果 |
| `field_mapping.txt` | 启用视场映射时生成 |
| `.TSC` | 保存到 Zemax DataDir 的 `Tolerance` 目录 |
| `.MF` | 保存到 Zemax DataDir 的 `MeritFunction` 目录 |
| Worst/Best Case | 由 Zemax API 开关统一控制 |

## 5. 模块划分

| 模块 | 职责 |
|---|---|
| `gui.py` | GUI、线程调度、日志展示 |
| `tol_run.py` | 命令行入口 |
| `toltool/pipeline.py` | 单一主流程：准备会话 + 运行蒙卡 |
| `toltool/zos_connect.py` | 连接 Zemax、另存工作副本、读取镜头信息 |
| `toltool/excel_io.py` | Excel 模板生成和配置读取 |
| `toltool/standard_templates.py` | 标准模板定义 |
| `toltool/current_settings.py` | 读取当前 TDE/MFE |
| `toltool/field_mapping.py` | 视场映射与插入工作副本 |
| `toltool/tde_builder.py` | 写 TDE |
| `toltool/mfe_builder.py` | 写/保存 MFE |
| `toltool/tsc_builder.py` | 生成 TSC |
| `toltool/tol_runner.py` | 配置并运行 OpenTolerancing |
| `toltool/ztd_reader.py` | 读取 ZTD 并导出统计 Excel |

主调用链：

```text
gui.py / tol_run.py
  → pipeline.prepare_session()
      → excel_io / current_settings / standard_templates
      → zos_connect
      → field_mapping
      → tde_builder
      → mfe_builder
      → tsc_builder
  → pipeline.run_montecarlo()
      → tol_runner
  → ztd_reader
```

## 7. 后续产品化规划

从已删除的“泛化需求文档”合并保留以下规划方向：

### 7.1 普通用户产品化

目标是让普通用户只需：

```text
选择镜头 → 选择标准模板 → 设置次数 → 开始分析 → 获取统计 Excel
```

重点改进：

- 模板由光学负责人定稿；
- GUI 文案更面向非开发者；
- 错误提示从 API 细节转为可操作建议；
- 输出目录只突出核心结果：统计 Excel、日志、ZTD。

### 7.2 模板维护

后续可增加模板维护能力：

- 产品线模板；
- 默认 MTF 频率；
- 默认公差等级；
- 默认 REPORT 项；
- 模板导入/导出。

### 7.3 公差资料识别

低优先级方向：

```text
结构公差资料 → 自动识别候选公差项 → 用户确认 → 写入 Excel 或 TDE
```

约束：识别结果必须人工确认，不能静默写入分析流程。
