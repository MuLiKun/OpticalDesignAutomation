## 4. 回归测试清单

### 4.1 基础检查

```powershell
.\.venv\Scripts\python.exe -m py_compile tolerance_analysis\gui.py tolerance_analysis\tol_run.py
```

建议覆盖核心模块：

```powershell
.\.venv\Scripts\python.exe -m py_compile tolerance_analysis\toltool\pipeline.py tolerance_analysis\toltool\tde_builder.py tolerance_analysis\toltool\mfe_builder.py tolerance_analysis\toltool\tsc_builder.py tolerance_analysis\toltool\tol_runner.py tolerance_analysis\toltool\ztd_reader.py tolerance_analysis\toltool\zos_connect.py
```

如 `check_stage1.py` 存在，可继续运行基础检查。

### 4.2 GUI 烟测

| 测试项 | 通过标准 |
|---|---|
| GUI 启动 | 无崩溃，主题和控件正常 |
| 模式切换 | 高级 Excel / 标准模板 / 当前设置控件显隐正确 |
| 路径选择 | zmx、Excel、输出目录可正常选择 |
| Standalone 运行 | 能启动 Zemax 并生成结果目录 |
| 取消/关闭 | 运行中取消和关闭保护有效 |
| 独立 ZTD 分析 | 选择已有 ZTD 后可导出统计 Excel |

### 4.3 三种主模式端到端

| 模式 | 检查内容 |
|---|---|
| 普通标准模板 | 自动主波长、结束面、视场映射、UUID 临时配置、统计 Excel |
| 当前设置 | TDE 不被清空，当前 MFE 有效行进入 REPORT |
| 高级 Excel | Excel → TDE → MFE → TSC → MC → ZTD → 统计 Excel 全链路 |

### 4.4 输出文件检查

每次运行结果目录至少应包含：

- 工作副本 `.zmx`；
- `used_excel.xlsx`；
- `run_config.json`；
- `run.log`；
- `.ZTD`；
- `_统计.xlsx`；
- 启用视场映射时的 `field_mapping.txt`。

同时检查 Zemax DataDir：

- `Tolerance\*.TSC`；
- `MeritFunction\*.MF`。

### 4.5 异常路径测试

| 场景 | 预期 |
|---|---|
| Excel 缺表头 | 读取阶段给出明确错误 |
| 面号/Min/Max 非数字 | 错误包含字段和值 |
| TSC 被占用 | 自动回退 `_api.TSC` 并记录日志 |
| ZTD 同名 TSC 缺失 | 统计不中断，列名可退化为 `colN` |
| GUI 交互扩展未打开 | 连接失败提示用户重新进入交互扩展 |
| 输出 Excel 被占用 | 改写备用文件或提示关闭占用 |

## 5. 真实 Zemax 回归建议

优先使用小样本：

- Monte Carlo 次数：2～5；
- 保存数量：0～2；
- 先跑 Standalone；
- 再补 Extension；
- 先标准模板，再高级 Excel，再当前设置。

记录信息：

- Zemax 版本；
- 镜头文件；
- 产品类型 RX/TX；
- 模板类型；
- 连接模式；
- MC 次数 / 保存数量；
- 是否启用视场映射；
- 是否生成 ZTD 和统计 Excel；
- 是否有名义值、REPORT 表头、COMP 项。
